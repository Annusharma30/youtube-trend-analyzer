# 🎬 YouTube Trending Video Analyzer - India

A data science project that fetches, analyzes, and visualizes 
YouTube trending videos in India using the YouTube Data API.

## 🚀 Features
- Fetches top 50 trending YouTube videos in India
- Performs sentiment analysis on comments using HuggingFace
- Interactive Streamlit dashboard with charts and insights

## 📊 Key Findings
- Music and Gaming dominate trending in India
- 75% of trending video comments are NEGATIVE
- Average views on trending videos: 1,358,732

## 🛠️ Tech Stack
- Python
- YouTube Data API v3
- HuggingFace Transformers
- Streamlit
- Pandas, Matplotlib, Seaborn

## ⚙️ Setup
1. Clone the repo
2. Install dependencies: pip install -r requirements.txt
3. Add your YouTube API key in .env file
4. Run: streamlit run app.py
